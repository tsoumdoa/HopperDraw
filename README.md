# HopperDraw

Persistent annotation lines, polylines, frames, curves (including freehand), text, and groups on the Grasshopper canvas in Rhino 8. Annotations belong to a **Hopper Draw** component and use absolute canvas coordinates. They stay in place when the component moves.

## Start drawing

1. Build the plugin for your Rhino runtime (see Development), then load the resulting `hopperborder.gha` through Grasshopper's component libraries folder and restart Rhino. Keep one copy installed.
2. Place **Hopper Draw** from **Params > Util**. Leave Active and Show enabled. Choose a tool in the component's **HopperDraw > Drawing > Tool** menu or through input M. A wired M input controls the tool and disables menu choices.
3. Focus the canvas and press and release **D twice**. The component footer shows `ON`; a bottom-centre chip shows the tool glyph, pen preview, tool name and shortcut letter. Action hints stay for about three seconds and fade; they remain visible during drafts and text editing. Use **Drawing > Pen** to set the next-shape style. While drawing, press **T** Text, **L** Line, **P** Polyline, **R** Frame, **C** Curve or **F** Freehand. **D D T** enters Text immediately; there is no suffix timing window. Tool letters require canvas focus, no modifiers/buttons, and no editor/menu/native interaction. Switching cancels the unfinished gesture; choosing the current tool does nothing. A wired M consumes the letter, shows **Disconnect M to switch tools**, and keeps the draft. External M tool changes keep drawing mode enabled.

Line and frame support **press-drag-release** and **click-click**. Polyline and curve add a vertex per click. **Enter** or **double-click** finishes an **open** stroke without a duplicate endpoint. With at least three distinct vertices, click the first point to close; a ring highlights it nearby. **Backspace** removes the last draft vertex. **Shift** snaps segments to 45-degree increments and makes frames square.

**Freehand (M=4)** uses hold-drag-release; Curve keeps click-to-add behavior. Freehand ignores Shift, Enter, Backspace and click counts. Release creates one curve, or closes a meaningful loop when released within the start ring (9 screen pixels). Clicks and tiny strokes create nothing. Escape, focus/capture loss, document changes, disabling the owner, or switching tools discard a held stroke, including its trailing mouse-up. The pen's **Smoothing > Low / Medium / High** choice is session-only (Medium by default). Sampling follows auto-pan, keeps open endpoints fixed and bounds long strokes for responsive drawing.

**Text (M=5)**: click for freely growing point text, or drag past the normal drag threshold for wrapping box text. Leftward/upward drags normalize the anchor to the rectangle's top-left; only width is retained, and height grows with content. Both forms have measured layout bounds with padding and can use Stroke and Fill for a box. Text starts with hidden stroke and no fill. **Text > Color** changes glyph colour; **Stroke > Color** changes the box border. Glyphs draw after fill/hatch and border, including with Stroke=None.

The inline multiline editor uses Enter for a newline. **Escape**, **Ctrl+Enter**, a click outside, or focus transfer commits once; ordinary outside clicks continue to their targets. Finishing that way from the **Text** tool also leaves drawing mode (like a design app returning to selection), so the next click selects or drags; press **D D T** for the next text. Pan/zoom, right-click and M changes commit but keep the tool. Pan/zoom commits at the first viewport change and closes the editor. Undo/redo, document switching, owner removal or lost editing eligibility abort the buffer. New blank text is discarded without undo; clearing existing text deletes it with one undo; changed text records once and unchanged text records nothing. Double-click text (also inside groups, in or out of drawing mode), or choose **Text > Edit text…**, to edit. Clipboard, Ctrl+A, local undo, Delete/Backspace, Ctrl+Backspace/Ctrl+Delete word deletion, arrows and IME stay in the editor; DD/tool keys are inactive there. Changing M while editing commits the buffer and keeps drawing enabled with the new tool. Editing layout may differ slightly from the canvas display layout.

Text presets use clean sans Segoe UI (system message font family fallback), in **canvas units**: **Title 48 semibold**, **Subtitle 28 regular**, **Body 16 regular**. Title uses Segoe UI Semibold when available, otherwise Bold. Line height is 1.3 em and box padding is 0.4 em; box width includes that padding. Size presets are 0.5/0.75/1/1.5/2/3/4x, with finite stored multipliers in (0.1,20]. Choosing a preset resets size to 1, Bold on for Title/off otherwise, and Italic off, retaining all colours and box styling. Size/preset changes widen narrow boxes enough to keep text visible. Explicit newlines and trailing spaces are retained; trailing spaces do not force a wrap or widen point text. Long words break by character. Below 3 projected pixels per em, grey bars replace glyphs without changing bounds. Selection, window/crossing and group bounds use the same cached layout. Text interiors pick even without a box; DrawOrder 0 still picks only the box edge. The single selected right-edge handle changes width and converts point text to box text, retaining its anchor and ignoring Shift snapping.

**Drawing > Pen > Text** controls the default Style/Size/Bold/Italic/Color. The text pen has its own box Stroke/Fill settings while Text is selected and is separate from the geometric pen, so returning to Line keeps its visible stroke. Use selection style for drawing copies a uniform text selection into the text pen. Both pens are session-only.

**Escape** cancels the current draft first; another press exits drawing mode. Completed shapes remain. The pen survives completion, cancellation, and exit/re-entry; only pen choices or **Reset pen to component defaults** change it. Drawing creates canvas annotations, with no outputs or Rhino model geometry.

## Inputs (stable order)

| Input | Default | Meaning |
| --- | --- | --- |
| Active (A) | true | Enable annotation editing and double-D activation. Inactive annotations still display. |
| Show (S) | true | Display annotations. Hiding cancels drawing. Locking the component also hides its annotations. |
| DrawMode (M) | 0 | 0 Line, 1 Polyline, 2 Frame, 3 Curve, 4 Freehand, 5 Text. Changing mode cancels an unfinished shape. |
| Color (C) | Black | Default annotation color; shapes can override it. |
| Thickness (T) | 8 | Base width in canvas units, clamped to 0.1-1000. Effective base times multiplier is capped at 1000. Non-finite input uses 8. |
| LineType (L) | 0 | 0 Solid, 1 Dash, 2 Dot, 3 DashDot, 4 DashDotDot. |
| DrawOrder (O) | 1 | 0 below wires/components (Groups channel); 1 above (Overlay). Previews and handles always use Overlay. |

Out-of-range mode, order, dash, or thickness inputs produce runtime warnings and safe values. Stroke widths scale with canvas zoom; handle sizes and picking tolerance stay approximately constant in screen pixels.

## Editing and menus

Click an unselected annotation to replace the selection. Press an already-selected body to preserve and move the entire mixed selection: annotations across owners and selected native GH objects. **Shift-click** adds, **Ctrl-click** removes without dragging the removed shape, and **Shift+Ctrl-click** toggles. Selected handles edit that annotation's geometry. A plain click on a previously unselected native GH object clears annotation selection; pressing an already-selected native object preserves it.

Empty-canvas selection uses GH's own selection rectangle: left-to-right **Window** requires the entire stroke inside; right-to-left **Crossing** includes strokes intersecting the rectangle, including closing edges and curve extrema. At release, Shift adds, Ctrl removes, and other modifier combinations replace. A plain empty-canvas click clears selection. **Ctrl+A** (GH Select All) also selects readable annotations and **Ctrl+D** (GH Deselect All) also clears them; GH still runs its own command, and **Ctrl+Shift+A** (GH Grow Selection) is untouched. Pressing a native grip, slider, toggle or other control that does not change GH's selection keeps the annotation selection; a press that replaces GH's selection replaces it too. **Delete** (or Backspace outside a draft) removes a mixed selection in one undo record. Text editing retains native handling.

Drag an annotation body or a selected native object to move the mixed selection. Selected native groups expand to their non-group descendants. Annotations entirely inside a selected native group's bounds at press also move, even when unselected, in either DrawOrder channel. This uses the same whole-shape test as Window selection, including stroke width and text bounds; blob/hull outlines are approximated by their bounding rectangle. Nested groups are covered by the selected outer group's bounds. Annotation groups move as whole units; partly-inside shapes stay put. The selected and contained sets are combined once without changing annotation selection. Contained unreadable shapes (including annotation groups with unreadable children) stay put; selected unreadable shapes block annotation movement with the existing warning. Shift constrains whole-selection movement horizontally/vertically. Shift snaps endpoint and polyline/curve vertex edits to 45 degrees relative to their anchor; frames retain their starting aspect. Annotation-led moves use press snapshots and record only on a changed release. **Escape, focus loss, capture loss, or document switching reverts the gesture and records nothing.** A native drag without selected or contained annotations is left entirely to GH. Polyline/curve drafts survive focus loss and other mouse buttons between clicks; switching documents cancels them. A click or a drag returning to its starting geometry creates no annotation undo record. Undo/redo clears transient annotation selection.

Native-led dragging follows snapping, Shift constraints and auto-pan. One undo restores the mixed move; if GH cannot record it, annotations return to their start. **Alt copy mode copies only native objects; selected and contained annotations return to their start.**

Grasshopper's Nudge commands (Alt+arrow in Rhino 8) also move selected annotations and annotations contained in selected groups, using containment before the move. Their undo actions join GH's nudge record, including same-direction key repeats, so one undo/redo restores the combined move. Follow requires a matching nudge pivot record and an actual uniform non-zero native translation; no native movement means no annotation movement. If GH reuses a nudge record after changing the native selection, annotation follow is withheld because that record belongs to different native targets. **Align/Distribute leave annotations in place.**

**Right-click a shape** for **Stroke > Color / Thickness / Line type / None**. None hides the stroke; toggle it again to restore it. Thickness presets remain 0.5x/1x/2x/3x/5x. Color includes named swatches, five session recent colors, Custom…, and Use component color.

**Fill** applies to text boxes, frames and closed polylines/curves (including freehand). Choose None, a color, Opacity (10/25/50/75/100%), Hatch, Hatch scale (0.5x/1x/2x/4x), and Hatch background. With Hatch=None the color is a solid fill; otherwise it is hatch ink over the optional background. Color alpha is multiplied by opacity. Fill=None turns off the entire fill layer while retaining dormant hatch settings. Background is ignored for solid fill. Patterns are Diagonal (ANSI31), CrossHatch, Concrete, Earth, Insulation, Brick, Grid, Dots, Horizontal and Vertical. Patterns use canvas units and canvas-origin phase, independent of zoom, with a 0.75-unit ink width; only visible bounds are generated and extreme primitive counts use a solid-ink fallback. Fill never inherits component color.

Style commands visit selected leaves across owners in one undo transaction, preserve nested group styles, and skip unchanged values. Mixed selections fill only eligible closed/text leaves; checks reflect that subset. **Use selection style for drawing** copies the complete uniform stroke/fill/hatch tuple and is disabled if any field is mixed. Selection styling otherwise leaves the pen alone. **Drawing > Pen** has Stroke, Fill and Smoothing; pen fill is disabled for Line and applies on completion when a shape is closed or is text. A completed shape with no effective paint is discarded with a brief HUD notice and no undo record.

A visible fill makes the whole interior pickable, including gaps between hatch marks; native-object priority is unchanged. Crossing selection also catches a rectangle wholly inside a filled region. **Exception — backdrops:** a component drawing below wires and components (DrawOrder 0) picks filled shapes by their outline only, so GH window selection, clicks and drags over a filled backdrop reach the canvas. Very fine hatches (cells under 3 screen pixels) paint as a light tint of the hatch colour; dense views render through a cached tile so paint cost stays bounded. Hidden stroke width does not enlarge window-selection bounds. Fully invisible shapes remain pickable only near the boundary, and have a thin dashed ghost when selected, hovered, or owned by the active drawing component. Selection outlines always follow the shared boundary, including self-intersecting curves (winding fill rule).

The same menu provides Bring to front / Send to back (within each owner, preserving relative order), Group / Ungroup, Duplicate, and Delete. Cross-owner grouping is disabled with an explanation. Groups remain pure containers, retaining each child's styles. Grouping uses the highest selected slot after removing the children: `[A,B,C,D]`, grouping A+C gives `[B,Group(A,C),D]`. Ungroup selects the restored children alongside other selected shapes. Duplicate offsets copies by 30 canvas units and assigns new shape GUIDs. Unreadable records block geometry movement and duplication atomically across affected annotation owners.

Right-drag on an annotation still pans; Ctrl+right-drag zooms. A contextual click changes selection only at release (Shift adds). In drawing mode, right-click empty canvas for Tool, Pen, Reset pen, and Exit drawing mode. The component menu groups **Drawing**, **Selection**, Select all annotations, Select unreadable annotation records, and Clear all under one **HopperDraw** submenu. Its mnemonic avoids the native Grasshopper siblings.

Every HopperDraw menu command has an underlined mnemonic: after right-clicking, press its letter to open or activate it without Alt. Each menu level has unique letters, including disabled commands. Tool mnemonics match L/P/R/C/F/T; recent colours use 1-5. Menu letters take precedence while a context menu or dropdown is open. Keyboard cues are rendered locally without changing Windows preferences or installing global shortcuts.

Drawing uses a thin crosshair with a centre gap, a light outline, an explicit centre hotspot and a small tool glyph outside the targeting area. Cursor bitmaps scale to 32/48/64 pixels at 100/150/200% DPI; Text mode uses an I-beam over existing text. The compact bottom-centre chip has a stroke sample, fill/hatch square when present, and a slashed none indicator for hidden stroke. It scales with DPI and clamps to narrow canvases. Notices use the same fade as action hints. The hint timer stops when feedback is static, including during a held draft/editor, and restarts for fading hints or notices.

Cursors identify drawing, movable bodies, and handles. Selected strokes have a light halo and dashed green outline without changing their stored colors. Text double-clicks open the editor; other annotation double-clicks outside drawing mode suppress GH search and leave geometry unchanged. Components, parameters and grips retain hit priority over annotation bodies; selected annotation handles take priority over native objects. A GH group's interior counts as empty canvas, so annotations inside groups can be picked, edited and drawn there; only a group's edge band (12 canvas units, 20 at the top) is native. HopperDraw changes the cursor only over its own targets and in drawing mode, never over GH's own wires, grips or controls. Overlay annotations precede Groups-channel annotations, then later owners and later shapes win.

Multiple components retain separate shape lists and selections; all eligible owners participate in editing. Double-D chooses the selected editable HopperDraw, then one with an annotation selection, then the first eligible owner. The drawing owner retains its drawing session. Read-only, inactive, hidden, and locked owners cannot capture input. Plain D remains reserved only while activation is eligible; text controls, native shortcuts, focus changes, and document switches interrupt activation.

Canvas-only shape edits and undo do not request a solution; tool input changes and native deletion may solve normally. Undo history does not survive reopening. Windows is the supported input path; the existing non-Windows fallback remains unverified. Editing yields conservatively in aborted documents and at the cluster icon corner.

## File format and recovery

This release uses annotation **format v1** and version **0.2.0.0**. Shape GUIDs survive save/load and undo; copies receive fresh IDs. Groups, text and freehand retain their own fields. Pens and smoothing are session-only. No legacy reader is provided: files from 0.1.6 and earlier are unsupported, and files saved by this version must not be re-saved with HopperDraw <=0.1.6.

Unknown optional data survives edits, duplication, undo and re-save. Invalid/unknown records stay opaque in their original slots and produce persistent warnings; readable neighbours remain usable. Opaque descendants block geometry movement/duplication atomically. Ungroup if necessary, then **Select unreadable annotation records > Delete** to remove them; Delete and Clear all are undoable. An unsupported major format or damaged list retains the entire annotation payload read-only. Open it with a compatible version to resolve it. A missing annotation chunk loads an empty editable component with a one-time pre-v1 notice.

Missing new optional style/text fields use silent defaults; missing older style fields report diagnostics. Component diagnostics persist until a successful read or Clear all; undo restores them. Present invalid types, enums, non-finite values or required geometry/text stay opaque, without guessing geometry at the origin. Text newlines normalize in memory, and positive stored narrow boxes display with enough content space to remain visible.

Interpretation limits are depth 32, 20,000 shapes, 200,000 points, finite coordinates within +/-10,000,000, and 100,000 text characters/10,000 display lines per shape. Box widths must be positive, at most 1,000,000, and fit within the coordinate limit. Full valid text remains stored when the display-line budget is reached. These limits bound interpretation; unknown raw data is retained.

## Development

Use Windows, Git, a .NET SDK supporting the declared targets, and the .NET Framework 4.8 runtime for the console tests. NuGet supplies the pinned Rhino/Grasshopper reference assemblies. The assembly/project name remains `hopperborder`; component and assembly GUIDs and all seven parameter slots remain unchanged.

```powershell
pwsh -NoProfile -File scripts/install-hooks.ps1
pwsh -NoProfile -File scripts/verify.ps1 -Quick
pwsh -NoProfile -File scripts/verify.ps1 -Full
```

Quick builds `net8.0-windows` Debug and runs every project under `Tests` by exit code, plus the hook snapshot script suite. Full builds Release for `net8.0-windows`, `net7.0-windows`, `net7.0`, and `net48`, then runs all tests. Both check that `yak/manifest.yml` matches the project version. Test projects are included in `hopperborder.slnx`; tests use the real plugin sources and GH assemblies without constructing a headless GH_Document.

The installer sets `core.hooksPath` to `.githooks`. Pre-commit verifies the staged snapshot with Quick; pre-push runs Full on each distinct outgoing commit tip. Working-tree changes cannot hide snapshot failures. The hooks use the shared NuGet cache and leave the index/worktree intact. `Tests/Hooks/snapshot-tests.ps1` checks isolation, different/multiple/duplicate pushed refs and deletions in disposable repositories. There is no hosted CI.

Implementation lives in the component/session files, `Shapes` (models and v1 serialization), and `Utilities` (canvas input, transactions, layout, menus and feedback). Tests compile the real sources; the unsupported fallback event path remains in `HopperDraw.cs`.

Run the [live Rhino checklist](docs/live-test-checklist.md) before release. Headless tests cover archive/model/bitmap/input regressions, not host undo-server dispatch, native selection event ordering, DPI behavior, or actual .gh/.ghx document integration. Build success for all targets is not a claim of live Mac support.
