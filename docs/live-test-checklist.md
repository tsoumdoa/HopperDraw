# Live Rhino 8 verification

## Setup/results

These checks are **live-only and not yet executed**. Install one HopperDraw build and start a new unsaved Grasshopper definition with HopperDraw, a slider and a panel. Keep untouched copies before damaging archives.

Record once: Rhino 8 build, .NET runtime, OS, plugin commit, Windows scaling, monitor transition, canvas size, and pass/fail plus observations for each scenario. Confirm version **0.2.0.0**, format **v1**, all seven input slots, and component/assembly GUIDs. Apply the zoom/DPI matrix to drawing, text, picking, handles, navigation, cursor and HUD checks: **25%, 100%, 400% zoom × 100%, 150%, 200% Windows scaling**. Restart Rhino after scaling if needed; also test mixed-DPI monitor moves and small/large editor zoom.

Headless verification covers real archive/model code, bitmap paint/clipping, snapshot swaps, draft decisions, recursive menu checks, native cursor resources, and a real WinForms keyboard/mouse loop. It does not establish live GH undo dispatch, interaction ordering, actual .gh/.ghx document integration, installed-font fallback/IME, or DPI/OS appearance. The pan transport fixture does not instantiate GH pan/zoom. Unknown payload storage remains proportional to the payload; parser budgets bound interpretation, not GH archive loading.

For repaint/solution checks, attach a temporary C# script subscription once and retain the delegates for cleanup:
